Two presentational attributes on `table` are obsolete. `<table bordercolor="#cccccc" height="400">` is how tables were framed and sized before CSS. The attributes colored the frame and sized the table. They still turn up in old pages and in HTML generated by older tools.

## Why avoid

They are obsolete. The HTML Standard lists both spellings among the attributes that "are obsolete (though the elements are still part of the language), and must not be used by authors", with the instruction: "Use CSS instead." The attributes keep working as presentational hints where engines honor them, in the weakest place in the author cascade, where any stylesheet rule for the same property wins.

So deleting one repaints the table wherever no stylesheet rule covers the property. Each attribute either does nothing, because CSS overrides it, or sets a value the stylesheet never states. Either way, part of the page design lives in markup, where nobody editing the CSS will look for it. MDN files the sibling hints under deprecated attributes with CSS beside each, and notes that no specification includes `height` while some engines honor it: use `min-height` instead.

## Use instead

Move the frame chrome to CSS and drop the hints:

```html
<table>
  <tr><td>Basic</td><td>CHF 9</td></tr>
</table>
```

```css
table {
  border-color: #ccc;
  min-height: 10rem;
}
```

## Detectability

Complete detection. The rule reports each `table` once, however many hints it carries. It checks the `table` element and nothing else. There is no autofix: removing a live hint repaints the table, so the move to CSS needs a human look at the values.
